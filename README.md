# آوای گندم

نرم‌افزار مدیریت فروشگاه نان فانتزی با رابط فارسی، مناسب ویندوز و گوشی Android.

## امکانات

- محصولات، موجودی و گردش انبار
- فروش سریع و فاکتور چندقلمی
- اشخاص، دریافت و پرداخت و چک‌ها
- اسناد حسابداری، هزینه‌ها و گزارش‌ها
- حقوق و دستمزد، شعبه و سال مالی
- رابط واکنش‌گرا و سایدبار جمع‌شونده
- نصب روی Android و اجرای آفلاین

## نصب روی ویندوز

فایل `AvayeGandom-Setup` را از بخش [Releases](https://github.com/mahdi-ghasemain/avaye-gandom/releases/latest) دریافت کنید. اطلاعات ویندوز در SQLite و روی همان رایانه ذخیره می‌شود.

## نصب روی Android

۱. از بخش [Releases](https://github.com/mahdi-ghasemain/avaye-gandom/releases/latest) فایل `AvayeGandom-Android` با پسوند APK را روی گوشی دانلود کنید.

۲. فایل APK را باز کنید. اگر Android درخواست کرد، برای مرورگر اجازهٔ «نصب برنامه‌های ناشناس» را فقط برای همین نصب فعال کنید.

۳. برنامه با آیکون مستقل و حالت تمام‌صفحه نصب می‌شود و برای کار روزانه به دامنه، هاست یا اینترنت نیاز ندارد.

اطلاعات موبایل داخل همان گوشی ذخیره می‌شود و به GitHub فرستاده نمی‌شود. حذف برنامه می‌تواند اطلاعات را پاک کند؛ از بخش گزارش‌ها مرتب فایل پشتیبان بگیرید.
